CollabXR Mod Packager
======================

The mod packager is a Unity package that allows `CollabXR`_ users to load their own content and visualizations.

See the `docs`_ for installation and usage instructions!

.. _CollabXR: https://envision.center/collabxr
.. _docs: https://envision-center.github.io/CollabXR-Documentation/modpackager.html
